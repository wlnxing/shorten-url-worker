# 界面设计规范

后台采用 [Ant Design](https://ant.design/docs/spec/introduce-cn/) 的信息层级、8px 栅格与反馈规范，使用 [Ant Design Vue 4](https://www.antdv.com/docs/vue/introduce-cn) 提供基础交互组件。

## 主题与组件

- `src/web/theme.ts` 是主题入口：品牌色、语义色、文字、边框、背景、字体、圆角和控件高度统一定义，供 `ConfigProvider` 与 CSS 变量共用。
- 默认使用靛蓝强调主要操作，中性色承载内容，绿色表示启用和成功，红色表示错误和删除操作。状态始终配合文字，不仅依赖颜色。
- 基础字号 14px、控件高度 40px、控件圆角 8px、内容面板圆角 12px；布局使用 8px 的倍数，紧凑间距以 4px 细分。
- Button、Input、Modal、Switch、Tag、Tooltip、Alert、Pagination、Skeleton、Spin 按组件路径导入，不全局注册整套组件。图标统一使用 `@ant-design/icons-vue`。
- 日期筛选继续使用浏览器原生日期控件。短链、访问与归档使用语义化 HTML 表格，以适应各自的数据结构。
- 不加载外部字体、图标 CDN 或图片；主题与资源均在站点内提供。

## 页面与反馈

桌面使用固定侧栏、顶部位置导航和自适应内容区。短链页突出创建与搜索；统计页按筛选、汇总、趋势、分布、明细排列；归档页展示保留策略、任务状态和目录。

数据读取使用骨架屏或明确的加载提示，空结果提供下一步操作。复制成功同时显示按钮状态与全局提示。创建和删除失败在当前弹窗内反馈，提交中禁用重复操作与关闭入口。

## 响应式与可访问性

- 760px 及以下使用底部导航，短链表格改为卡片，复制、编辑、统计和删除保留文字说明。明细和归档表格可横向滚动。
- 表单保留明确标签和浏览器校验；图标操作提供可访问名称与提示。
- 支持键盘焦点、跳过导航、弹窗焦点管理和屏幕阅读器状态通知。
- 使用系统字体，并响应 `prefers-reduced-motion` 减少动画。

修改界面后运行 `npm run check`，并使用 Chrome MCP 检查桌面与手机布局、真实管理操作、错误反馈及空状态。
